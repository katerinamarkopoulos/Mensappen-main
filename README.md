# Mensappen
En app för att logga mens och få hem mensskydd

## Webbapp (HTML + CSS)

Öppna `index.html` i en webbläsare.

| Fil | Skärm |
|---|---|
| `index.html` | Översikt (Hej Fina!) |
| `logga.html` | Logga din mens |
| `leverans.html` | Mensen närmar sig |
| `paket.html` | Ditt paket |
| `rackte.html` | Räckte ditt paket? |
| `kalender.html` | Kalender (månadsvy med mens, beräknad mens, ägglossning) |
| `profil.html` | Profil och inställningar |

`styles.css` innehåller alla stilar (färger som variabler i `:root`). `app.js` sköter chips, räknare, totalsumma och kalendern.
